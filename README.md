# notepad
메모장앱 — 설치 없이 브라우저에서 바로 쓰는 로컬 메모장

## 기능
- 새 메모 · 자동 저장(입력 멈추고 0.4초 후) · 삭제(확인창)
- 첫 줄을 제목으로 사용, 고정(📌) 메모는 목록 맨 위
- 여러 단어 검색(모든 단어 포함, 대소문자 무시)
- 글자·단어·줄 수 표시
- 메모 한 개를 `.txt`로 저장, 전체를 JSON으로 백업·가져오기(같은 메모는 최신본 유지)
- 다른 탭에서 수정한 내용 자동 반영, 다크 모드, 모바일 화면 지원
- 단축키: `Ctrl+S` 즉시 저장, `Ctrl+Alt+N` 새 메모

## 실행
`index.html`을 브라우저로 열면 됩니다. 서버·설치가 필요 없습니다.

## 데이터
메모는 이 브라우저의 `localStorage`에만 저장되고 외부로 전송되지 않습니다.
브라우저 데이터를 지우면 메모도 지워지므로, 중요한 메모는 **백업 내보내기**로 JSON을 보관하세요.

## 파일
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 |
| `app.js` | 화면 동작 |
| `notes.js` | 메모 데이터 로직(정렬·검색·가져오기 등, UI 없음) |
| `notes.test.js` | 단위 테스트 — `node --test` |

## 검증
- 단위 테스트 8개 통과 (Node 22)
- Chromium 자동 점검: 생성·검색·새로고침 후 유지·고정·백업/복원·삭제·모바일 폭·콘솔 오류 없음
